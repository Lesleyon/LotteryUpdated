Для запуска был написан следующий ReadMe:
Настольное бэк-энд приложение создающее тиражи и билеты лотереи 
Использован язык: Java 21
Сборка: Maven
База Данных: PostgreSQL18
Есть несколько способов запуска
Первый:
1.	Скачиваем код с гитхаба
2.	Разархивируем
3.	Открываем в Inteleji Idea или в любом другом редакторе поддерживающем проекты на языке java
4.	Разрешаем редактору работать с скаченным из интернета кода
5.	Заходим в DatabaseConnector и меняем данные под свою базу данных
6.	Выполняем скрипт DatabaseScript.sql в вашей базе данных
7.	Пишем команду cd {путь}\ LotteryUpdated в терминал, если редактор автоматически не перекинул в терминал проекта
8.	Заходим в /mainframe/Main.java
9.	Активируем Main.java
10.	Сервер открывается на http://localhost:8080
11.	Используем команду curl или curl.exe для выполнения команд
Второй:
1.	Скачиваем jar файл
2.	Создать в PostgreSQL новую базу данных с именем Server_database
3.	Выполняем скрипт DatabaseScript.sql в вашей базе данных
4.	Открываем консоль 
5.	Вводим java –jar {путь}/LotteryUpdated.jar
6.	Сервер открывается на http://localhost:8080
7.	Далее используя команду curl или curl.exe вводятся все эндпоинты

Третий:
1.	Скачиваем весь проект
2.	Заходим в Inteleji
3.	Устанавливаем плагин Docker
4.	Заходим в {путь}\ LotteryUpdated в консоле, если нет 
5.	Вводим в консоль команду docker-compose up -d, чтобы поднять базу данных и контейнер приложения
6.	Открываем консоль
7.	Вводим docker images
8.	Находим lottery-db и lottery-app и проверяем, активны ли они
9.	Сервер открывается на http://localhost:8080
10.	Используем команду curl или curl.exe для выполнения команд
11.	Для закрытия контейнера используем docker compose down
